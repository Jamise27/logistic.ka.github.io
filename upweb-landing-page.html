Tên miền (Custom Domain)

Địa chỉ dễ nhớ, thay thế cho dãy số IP khó nhớ của máy chủ

Vì sao cần tên miền?

Mọi máy tính kết nối Internet đều có 1 địa chỉ IP công cộng, ví dụ IPv4: 173.194.121.32 hoặc IPv6: 2027:0da8:8b73::8a2e:0370:1337.

Địa chỉ IP máy tính xử lý rất dễ, nhưng con người thì khó nhớ và IP có thể đổi theo thời gian → cần tên miền (domain) là chuỗi ký tự dễ đọc, dễ nhớ hơn.

Domain gồm những phần nào?

www.example.com

  • Label / SLD — nhãn/tên miền cấp 2, đứng ngay trước phần mở rộng (vd: example)
  • TLD (Top Level Domain) — đuôi miền, đứng cuối cùng (vd: .com)
Ví dụ dễ hiểu: nếu địa chỉ IP là toạ độ GPS (chính xác nhưng khó nhớ: 21.0285° N, 105.8542° E), thì tên miền chính là địa chỉ nhà viết tay (dễ nhớ: "36 Phố Cổ, Hà Nội") — DNS chính là "người phiên dịch" chuyển địa chỉ dễ nhớ đó thành toạ độ GPS chính xác để bạn đến đúng nơi.

Web Hosting

Nơi lưu trữ toàn bộ dữ liệu, database của website

Hosting hoạt động như thế nào?

Khi người dùng gõ tên miền lên trình duyệt, hosting sẽ chuyển tất cả file cần thiết (HTML, CSS, JS, ảnh...) từ web server đến trình duyệt đó để hiển thị trang web.

Website tĩnh cần gì?

Với website tĩnh (static — không xử lý dữ liệu phía server), hosting chỉ cần lưu: hình ảnh, HTML, CSS, JavaScript. Không cần cơ sở dữ liệu hay ngôn ngữ backend (PHP, Node.js...).

Ví dụ dễ hiểu: nếu website là 1 cửa hàng, tên miền là địa chỉ ghi trên biển hiệu để khách tìm ra cửa hàng, còn hosting chính là mặt bằng thực tế nơi hàng hoá (file website) được chứa và trưng bày. Không có hosting, tên miền chỉ là 1 tấm biển trỏ vào... một khoảng đất trống.
🏢 Hosting provider phổ biến: Bluehost, HostGator, GoDaddy, DreamHost 🛠️ Công cụ quản lý dịch vụ lưu trữ phổ biến: cPanel

Hosting miễn phí với GitHub Pages

Đưa website tĩnh lên mạng chỉ trong vài bước, hoàn toàn miễn phí

Bước 1 — Tạo Repository mới

Vào GitHub → New repository. Đặt tên kho lưu trữ (repository name) — rất quan trọng: phải là tên-người-dùng.github.io (đúng username GitHub của bạn + .github.io).

vd: username = "thanh2026"
→ tên repo: thanh2026.github.io

Bước 2 — Tải file lên

Bấm "uploading an existing file" để tải các file website (HTML/CSS/JS) lên repo. Cũng có thể sửa file trực tiếp trên GitHub bằng icon cây bút (pen/edit).

Bước 3 — Bật GitHub Pages

Vào Settings → Pages → chọn nhánh chính main (thư mục root) → Save.

Sau vài phút, web sẽ được public tại địa chỉ mặc định của GitHub Pages.

Bước 4 — (Tuỳ chọn) Gắn tên miền riêng

Nếu đã mua tên miền riêng, vào Settings → Pages → Custom domain, nhập tên miền của bạn vào ô đó rồi Save. Bước này cần đi kèm cấu hình DNS ở nhánh tiếp theo.

Kết quả: web đã được đưa lên mạng, truy cập được tại địa chỉ mặc định dạng https://tên-người-dùng.github.io — hoàn toàn miễn phí, không cần mua hosting.
⚡ Phù hợp cho: portfolio cá nhân, CV online, landing page học tập, tài liệu dự án ⚠️ Chỉ hỗ trợ website tĩnh — không chạy được backend (PHP, Node.js server...)

Cấu hình DNS (Domain Name System)

"Danh bạ điện thoại" của Internet — trỏ tên miền riêng về đúng hosting/server

Muốn dùng tên miền riêng (vd: mysite.com) thay vì địa chỉ mặc định username.github.io, bạn cần khai báo DNS record tại nhà cung cấp tên miền (GoDaddy, Namecheap, Cloudflare...) để trỏ về GitHub Pages.

Các bước cấu hình

BướcThao tác
1Truy cập DNS Provider — đăng nhập vào nơi bạn đã mua tên miền
2Thêm bản ghi CNAME (nếu dùng subdomain như www)
3Hoặc thêm bản ghi A Record (nếu dùng domain gốc, apex domain)
4Xác nhận và chờ DNS Propagate — có thể mất 1–24 giờ

📌 CNAME Record

Host  : @ hoặc www
Value : username.github.io
Type  : CNAME

Dùng khi muốn trỏ 1 subdomain (như www.mysite.com) sang địa chỉ GitHub Pages.

📌 A Record

Type  : A
Name  : @
Value : 185.199.108.153
        185.199.109.153
        185.199.110.153
        185.199.111.153

Dùng khi muốn trỏ domain gốc (apex, không có www) — cần khai báo đủ cả 4 địa chỉ IP của GitHub Pages để đảm bảo độ ổn định.

Ví dụ dễ hiểu: DNS giống hệt tổng đài 1080 (danh bạ điện thoại) — bạn gọi hỏi "cho tôi số của GitHub Pages", DNS tra ra "à, số đó là 185.199.108.153" rồi tự động nối máy tới đó. CNAME giống việc "chuyển tiếp cuộc gọi" sang 1 số khác (username.github.io), còn A Record là "số điện thoại trực tiếp" (địa chỉ IP) — cả 2 đều đưa bạn đến đúng nơi, chỉ khác cách trỏ.
⏳ DNS Propagation: thời gian để thay đổi DNS lan truyền khắp các máy chủ DNS toàn cầu — thường 1-24 giờ, đôi khi lâu hơn 💡 Có thể dùng đồng thời: CNAME cho www + A Record cho domain gốc, để cả 2 dạng URL đều hoạt động

🌱 Kiến thức mở rộng — các loại DNS record khác

Loại recordChức năng
ATrỏ domain tới 1 địa chỉ IPv4
AAAATrỏ domain tới 1 địa chỉ IPv6
CNAMETrỏ 1 subdomain sang 1 domain khác (alias)
MXChỉ định máy chủ nhận email cho domain (mail server)
TXTLưu văn bản tuỳ ý — thường dùng để xác minh quyền sở hữu domain
